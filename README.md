## Deploy na Vercel

### Opção 1 — Via GitHub (recomendado)

1. Crie um repositório no GitHub
2. Envie o código:

```bash
git init
git add .
git commit -m "Portfólio profissional Isac Cavalheiro"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/portfolio-isac.git
git push -u origin main
```

3. Acesse [vercel.com](https://vercel.com) e faça login com GitHub
4. Clique em **"Add New Project"**
5. Importe o repositório
6. Framework Preset: **Other** (site estático)
7. Clique em **Deploy**

### Opção 2 — Via CLI

```bash
npm i -g vercel
vercel
```
